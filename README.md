# GRC Grid marketing website

A standalone HTML, CSS and JavaScript website. No package installation or build step is required.

## Run

Extract the ZIP and open index.html in a modern browser.
Alternatively, from the extracted grc-grid folder run:

    python3 -m http.server 8000

Then visit http://localhost:8000.

## Files

- index.html: page structure, content and SVG relationship diagrams.
- style.css: palette, responsive layouts and animations.
- app.js: assurance journey, graph selector, agent tabs, integration filters, mobile navigation and motion controls.

## Edit and deploy

Edit these files directly. Upload index.html, style.css and app.js together to any static website host, keeping them in the same directory.

The contact link opens an email to contact@nuvriqai.com. There is no backend or lead-submission service. Agent and integration interactions illustrate the proposed product; they do not connect to live enterprise systems.
